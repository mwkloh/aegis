# aegis

Canonical state lives outside this repo:

- `~/.aegis/workspace/` — agent workspace (memory, sessions, identity)
- `~/.aegis/workspace/skills/` — AEGIS skill catalog (descriptors + co-located scripts; seeded from `runtime/skills/_bundle/` on first boot)
- `~/.aegis/.env` — secrets
- `~/.aegis/config.json` — runtime config
