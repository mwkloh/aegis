## 0. Purpose

Deliver, with no surprises:

1. A clean, sovereign AEGIS home at `~/.aegis/workspace/` seeded from `~/.atamai/workspace/`.
2. A Phase 0 repo scaffold that obeys the three-plane separation (Runtime / Reflection / Improvement).
3. A **walking skeleton**: CLI message → intent classification → skill registry lookup → `echo` skill → harness adapter → response, end-to-end, with structured progress events and tests.

Nothing else. No Telegram. No Obsidian. No real tools. No memory writes. No reflection. No coding harness automation. Those are later phases.

## 2. Pre-flight (no app code; file moves only)

These are filesystem and git operations only — no application code is written.

### 2.1 Bootstrap `~/.aegis/`

```bash

mkdir -p ~/.aegis/workspace/memory
mkdir -p ~/.aegis/workspace/sessions
mkdir -p ~/.aegis/workspace/skills        # seeded on first boot from runtime/skills/_bundle
```

### 2.2 Copy canonical files (idempotent, never overwrite if target exists)


From `~/.atamai/workspace/` → `~/.aegis/workspace/`:
- `AGENTS.md`, `USER.md`, `IDENTITY.md`, `SOUL.md`, `HEARTBEAT.md`
- `SKILLS_INDEX.md` (will be regenerated by AEGIS later, but seed text is useful)
- `memory/MEMORY.md`

> The `skills/` tree is **not** copied. The `sessions/` history is **not** copied. The `memory-index.db` is **not** copied (AEGIS builds its own).

### 2.3 Copy + adapt env and config

- `cp ~/.atamai/.env ~/.aegis/.env`
- `cp ~/.atamai/config.json ~/.aegis/config.json`
- Edit `~/.aegis/.env`: rename `ATAMAI_HOME` → `AEGIS_HOME=~/.aegis/workspace`; rename `ATAMAI_API_KEY` → `AEGIS_API_KEY` (or remove if HTTP API isn't a Phase 0 surface — it isn't).
- Edit `~/.aegis/config.json`: leave structure intact, change identifiers (e.g., any `"atamai"` strings → `"aegis"`), confirm Ollama base URL, confirm Telegram allowlist (kept dormant — used in Telegram phase).

### 2.4 Repo hygiene

- Add `.gitignore` rules for: `__pycache__/`, `.venv/`, `*.db`, `*.db-shm`, `*.db-wal`, `.env`, `.env.local`, `coding_harness/diffs/*.patch`, `runtime/harness/openharness/` (if vendored as submodule, that path will be excluded from main tracking).
- Confirm no secret has ever been committed to `mwkloh/aegis` (we know the repo only has `1e57711 first commit` so we'll inspect that diff).

**Acceptance for §2:** `~/.aegis/workspace/` exists with the six canonical .md files and an empty `memory/`, `sessions/`, `skills/`. `~/.aegis/.env` and `~/.aegis/config.json` exist and load cleanly. Repo `.gitignore` blocks every secret path.

### 3.2 Plane README contract

`runtime/README.md` opens with the verbatim block:

> This directory is **Plane 1 (Runtime)**. Code here MAY: classify intent, select skills, emit tool-intent contracts, route to the harness, stream progress, render replies. Code here MUST NOT: modify its own files, mutate canonical memory (`USER.md`, `IDENTITY.md`, `SOUL.md`, `AGENTS.md`, `MEMORY.md`, `HEARTBEAT.md`), apply improvements, or write to `improvement/` or `coding_harness/`. Violations are bugs.

Equivalent guard READMEs go in `memory/`, `improvement/`, `coding_harness/`.

### 3.3 Dependencies (pyproject.toml — Phase 0 minimum)

```text
runtime  : httpx, pydantic, pyyaml, python-dotenv, structlog, ollama (client), tenacity
memory   : sqlite-utils, sqlite-vec
testing  : pytest, pytest-asyncio, pytest-mock, respx (httpx mocking)
quality  : ruff, mypy, bandit, semgrep (already on system)
```

OpenRouter is reached via plain `httpx` (no SDK lock-in). OpenHarness will be added later as a git submodule under `runtime/harness/openharness/` once we drive a real tool — for Phase 0 the adapter has an `in_process` mode that runs `echo_tool.py` directly.

### 3.4 Security defaults baked into Phase 0

- All YAML loaded with `yaml.safe_load`.
- All XML (later Obsidian-attached content): `defusedxml`.
- HTML sanitization (later Obsidian render): `bleach`.
- `.env` never read from cwd — only from `~/.aegis/.env` resolved via `Path.home()`.
- Pydantic validates every external boundary: CLI input, Ollama response, OpenRouter response, skill descriptor, tool-intent contract.
- `bandit` + `semgrep` run in CI from day 1; `ruff` + `mypy --strict` block PRs.

**Acceptance for §3:** `make setup && make test` is green on a clean checkout. `scripts/doctor.py` reports OK. No file under `runtime/` writes to any path under `~/.aegis/workspace/*.md`, `improvement/`, or `coding_harness/` (enforced by an integration test that monkeypatches `open()` for write-mode and asserts no canonical path is touched).

## 4. Walking Skeleton — the `echo` vertical slice

### 4.1 What it does

```text
$ aegis chat
> echo hello world
[event] received: "echo hello world"
[event] intent.classified: {"intent": "echo", "confidence": 0.97}
[event] skill.selected: {"skill_id": "echo"}
[event] reasoning.contract_emitted
[event] harness.tool_started: {"tool": "echo_tool"}
[event] harness.tool_completed: {"tool": "echo_tool"}
[event] reply.ready
hello world
>
```

### 4.2 Components & contracts

- **`chat/cli.py`** — async REPL using `prompt_toolkit` (or stdlib `input()` + `asyncio.to_thread` to keep deps minimal). Reads one line, ships it through the pipeline, prints events + final reply. `--json` flag prints raw events only (for tests).
- **`intent/classifier.py`** — calls Ollama `gemma4:e2b` with a tiny structured prompt; output is constrained JSON `{intent, confidence}` validated by Pydantic. Cached on identical input.
- **`skills/registry.py`** — loads every `*.yaml` under `skills/catalog/` at startup, validates against `docs/SKILLS_SCHEMA.md`, exposes `find_by_intent(intent: str) -> Skill | None`. **Read-only at runtime.**
- **`skills/catalog/echo.yaml`** — minimal valid descriptor:

  ```yaml
  skill_id: echo
  description: "Echo the user's message back verbatim. Plumbing test only."
  trigger_intents: [echo, ping]
  allowed_tools: [echo_tool]
  memory_read: []
  memory_write_policy: { proposal_only: true, requires_review: true }
  constraints: { max_steps: 1, risk_level: low }
  progress_events: [reply_ready]
  ```

- **`reasoning/skill_runner.py`** — given `(message, skill)`, emits a tool-intent contract. For `echo` this is purely deterministic (no LLM call) — proves the boundary: skills are scaffolds, not "ask the model nicely."
- **`harness/contract.py`** — Pydantic `ToolIntent`, `Step`, `ToolResult`, `HarnessEvent`. JSON schema exported to `runtime/harness/contract.schema.json` for cross-language validation later.
- **`harness/adapter.py`** — `Harness.execute(contract) -> AsyncIterator[HarnessEvent]`. Phase 0 mode: `in_process` — dispatches to `tools/echo_tool.py`. Future modes: `subprocess`, `service`. The interface does not change.
- **`harness/tools/echo_tool.py`** — pure function `def run(args) -> dict`. No I/O.
- **`model_router/router.py`** — single function `for_tier(tier: int) -> ModelClient`. Tier 0 → Ollama; Tier 1 → OpenRouter (instantiated but unused in Phase 0); Tier 3 → never returns an LLM (raises).
- **`events/stream.py`** — append-only JSONL writer to `~/.aegis/workspace/sessions/{session_id}.jsonl` + structured console echo. **This is the only Phase 0 write to `~/.aegis/workspace/`.**

### 4.3 What is deliberately NOT in the skeleton

- No memory reads. The echo skill declares `memory_read: []`.
- No memory writes anywhere (sessions JSONL is execution memory, owned by the harness layer per the spec).
- No retries, no fallback model, no Tier 1 invocation, no Tier 2 escalation.
- No Telegram, no Obsidian, no FastAPI HTTP, no Reflection.
- No `improvement/` or `coding_harness/` automation.

### 4.4 Tests (TDD, written before implementation)

| Test | What it pins down |
| --- | --- |
| `test_config_loads.py` | `~/.aegis/.env` + `~/.aegis/config.json` parse; required keys present. |
| `test_intent_classifier.py` | Mocks Ollama via `respx`; asserts schema validation, retry on malformed JSON. |
| `test_skill_registry.py` | Loads `echo.yaml`, rejects malformed YAML, rejects schema violations, is read-only (mutating returned object does not affect registry). |
| `test_harness_contract.py` | Round-trips `ToolIntent` JSON; rejects extra fields; rejects unknown tool ids. |
| `test_echo_skill_e2e.py` | Drives `cli.py --json` with `"echo hello world"`, asserts the exact event sequence and final reply, asserts session JSONL written under tmp `AEGIS_HOME`. |
| `test_plane_isolation.py` | Walks `runtime/`, asserts no module imports from `improvement/` or `coding_harness/`; asserts no write-mode `open()` targets any canonical .md file. |

**Acceptance for §4:** `pytest -q` green. Manual `aegis chat` produces the event trace in §4.1. CI gate (`ruff`, `mypy --strict`, `bandit`, `pytest`) green.

## 6. Risks & open items

| Risk | Mitigation |
| --- | --- |
| `gemma4:e2b` returns malformed JSON for intent | Strict Pydantic + retry-once with stricter system prompt; on second failure → confidence=0, fallback intent="unknown". |
| Adapter abstraction over OpenHarness leaks | Lock down `HarnessEvent` schema now so swapping `in_process` → `subprocess` later is invisible to callers. |
| Canonical files diverge between `~/.atamai/` and `~/.aegis/` once both run | Document `~/.aegis/` as sovereign; atamai becomes legacy. Add a `scripts/diff_canon.py` utility for any future merge. |
| Secrets in `~/.atamai/.env` accidentally committed | `.env*` globally gitignored; `bootstrap_aegis_home.py` refuses to copy if target exists; CI runs `gitleaks` on every PR. |
| `gemma4:e2b/e4b` model name is non-standard (Ollama tag may rotate) | Pin via SHA256 in `~/.aegis/config.json` `models` block; doctor verifies digest at startup. |

## 7. Definition of Done (this plan)

A reviewer can:

1. Run `python scripts/doctor.py` → all green.
2. Run `make test` → all green.
3. Run `aegis chat`, type `echo hello`, see the event trace and the reply.
4. Open `~/.aegis/workspace/sessions/<id>.jsonl` and read every event.
5. Try to make `runtime/` write to `~/.aegis/workspace/USER.md` → integration test fails the build.

When all five hold, Phase 0 + walking skeleton are done and we move to either Telegram or the Obsidian read slice (your call).
