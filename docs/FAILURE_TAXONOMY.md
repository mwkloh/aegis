# AEGIS — Failure Taxonomy

Canonical classification of execution failures and friction signals.

---

## Categories

### Tool Failures
- Timeout
- Invalid arguments
- Permission denied
- Empty / null result

### Reasoning Failures
- Wrong skill selected
- Incorrect tool sequencing
- Missing prerequisite step

### Memory Failures
- Irrelevant retrieval
- Missing context
- Over-retrieval

### Interaction Failures
- User correction
- Clarification loop
- Aborted task

---

## Usage

Each failure must map to exactly one primary category.
