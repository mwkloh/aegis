# Skills Index

Skills live in `skills/` (seeded from the bundled set on first boot). Each one is a YAML descriptor naming its trigger intents, its allowed tools and its argument schema; see `docs/SKILLS_SCHEMA.md` in the repository.

Add your own with `aegis-skill-add`. List what is installed by looking in `skills/`.
